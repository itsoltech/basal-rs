# Oprawa repozytorium

- `basal-rs-banner.svg` — polski baner README z autorstwem modeli i silnika, edytowalny SVG bez zewnętrznych fontów i zasobów.
- `social-preview.png` — grafika podglądu udostępnianego linku, 1280 × 640 px.

Opis repozytorium na GitHubie:

> Rust inference engine for Basal models by Remek Kinas. GPU execution and HTTP serving with CUDA & Metal backends. Benchmarks against upstream.

Tematy: `rust`, `basal`, `inference`, `cuda`, `metal`, `apple-silicon`,
`decision-making`, `typesafe`.

## Wgranie grafiki podglądu

1. Otwórz [Settings → General](https://github.com/itsoltech/basal-rs/settings).
2. W sekcji **Social preview** wybierz **Edit → Upload an image** i wskaż `social-preview.png` z tego katalogu.
3. Zatwierdź grafikę. Serwisy społecznościowe mogą jeszcze pokazywać poprzedni podgląd z cache.

Cytat autora w README pochodzi z [wpisu Remka Kinasa na X](https://x.com/KinasRemek/status/2107539877839384742).
Dotyczy przeglądu basal-rs; nie zastępuje pomiarów zgodności ani wydajności.

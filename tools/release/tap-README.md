# itsoltech/homebrew-tap

Homebrew formulas of [IT SOL](https://github.com/itsoltech).

```sh
brew install itsoltech/tap/basal-rs
basal doctor
basal serve
```

| Formula | |
|---|---|
| `basal-rs` | [basal-rs](https://github.com/itsoltech/basal-rs): Rust runtime of the Basal decision models (Apple Silicon, Metal) |

The formulas are updated by the release workflow of each project.
